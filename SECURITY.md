# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/dvc-labs/sum/security/advisories/new), or DM a maintainer in the [dvc.labs Discord](https://discord.gg/dRxSt8Bt9t).

Please include what you found, how to reproduce it, and what impact you think it has. You'll get a reply within a few days.

## Supported versions

Only the latest release of Sum is supported. The hosted bot always runs the latest version.
